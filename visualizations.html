Data Cleaning & Preparation

Turning Raw Data into Analysis-Ready Data

Objective: clean, validate, transform, and document the student success dataset before building the SQL tables, exploratory visuals, and final analysis. The workflow below addresses missing values, duplicates, data types, inconsistent formats, invalid values, outliers, categorical inconsistencies, and transformations.

Cleaning Audit Checklist

Issue Validation Rule Resolution
Missing valuesCheck null count per column and outcome group.Impute documented numeric medians, keep meaningful binary flags, and remove unusable rows only when target/outcome is absent.
Duplicate recordsCompare student identifiers and full-row duplicates.Retain one canonical record and log removed duplicates.
Incorrect data typesConfirm grades are numeric, binary fields are 0/1, and target is categorical.Cast numeric columns, convert coded flags, and store categories as readable labels.
Inconsistent formatsStandardize labels, spaces, capitalization, and grade scales.Normalize strings and keep grades on the source 0-20 or 0-200 scales.
Invalid valuesValidate age, grades, credits, tuition status, and scholarship status against allowable ranges.Correct obvious encoding issues, otherwise flag and exclude from affected calculations.
OutliersUse IQR fences for age, grades, approved units, and unemployment/inflation indicators.Keep legitimate extreme students, winsorize only derived modeling fields, and document decisions.
Inconsistent categorical valuesMap coded values to a controlled dictionary.Create consistent labels such as Dropout, Enrolled, Graduate, Daytime, Evening, Yes, and No.
Data transformationsDerive interpretable fields for analysis.Create age bands, risk tier, total approved units, tuition status label, and SQL-ready dimension keys.

Preparation Pipeline

1. Profile

Generate row counts, null counts, unique values, min/max checks, and category frequency tables.

2. Validate

Apply range rules: age 17-70, admission grades 0-200, semester grades 0-20, and binary fields limited to 0/1.

3. Transform

Create analysis fields such as academic risk tier, total first-year approved units, payment status, and age band.

4. Document

Maintain a data dictionary, cleaning log, SQL schema notes, and assumptions used in every visualization.

SQL Data Analysis

From Student Data to SQL Questions

Objective: turn the cleaned student records into SQL tables and show how basic SQL commands can answer questions about dropout risk. The query results are then turned into charts.

Fact Table

student_outcomes

One row per student with grades, approved units, tuition status, scholarship status, age, and target outcome.

Dimension Table

dim_program

Program, attendance shift, degree area, and course metadata for JOIN-based comparisons.

Dimension Table

dim_student_profile

Student background and money labels, including age group, debt label, and scholarship label.

-- 1. Basic selection
SELECT student_id, target, admission_grade, age_at_enrollment
FROM student_outcomes
LIMIT 10;
-- 2. Filtering with WHERE
SELECT student_id, target, tuition_fees_up_to_date
FROM student_outcomes
WHERE target = 'Dropout'
  AND tuition_fees_up_to_date = 0;
-- 3. Multiple conditions
SELECT student_id, target, approved_units_sem1, grade_sem1
FROM student_outcomes
WHERE approved_units_sem1 < 3
  AND grade_sem1 < 10;
-- 4. Sorting with ORDER BY
SELECT student_id, target, age_at_enrollment, grade_sem1
FROM student_outcomes
ORDER BY age_at_enrollment DESC, grade_sem1 ASC;
-- 5. Aggregation
SELECT target,
       COUNT(*) AS students,
       ROUND(AVG(admission_grade), 1) AS avg_admission_grade
FROM student_outcomes
GROUP BY target;
-- 6. Group comparison
SELECT scholarship_holder,
       target,
       COUNT(*) AS students
FROM student_outcomes
GROUP BY scholarship_holder, target
ORDER BY scholarship_holder, students DESC;
-- 7. HAVING for high-risk groups
SELECT age_band,
       ROUND(AVG(CASE WHEN target = 'Dropout' THEN 1 ELSE 0 END) * 100, 1) AS dropout_rate
FROM dim_student_profile p
JOIN student_outcomes s ON s.student_id = p.student_id
GROUP BY age_band
HAVING COUNT(*) >= 100
ORDER BY dropout_rate DESC;
-- 8. JOIN program details to outcomes
SELECT pr.attendance_shift,
       s.target,
       COUNT(*) AS students,
       ROUND(AVG(s.approved_units_sem1), 2) AS avg_approved_units
FROM student_outcomes s
JOIN dim_program pr ON s.program_id = pr.program_id
GROUP BY pr.attendance_shift, s.target
ORDER BY pr.attendance_shift, students DESC;

SQL Chart 1: Dropout Rate by Age Group

Generated from the HAVING query that compares age bands with sufficient sample size.

Source & method: Kaggle dataset values were found with a SQL GROUP BY on derived age bands and a HAVING filter to keep age groups with enough records.

SQL Chart 2: Class Schedule Outcomes

Generated from the JOIN query connecting program attendance shift to student outcomes.

Source & method: Kaggle dataset values were found by joining student outcomes to program shift labels, grouping by shift and Target, then stacking the outcome percentages.

Research Connection

SQL queries support the research questions by making risk comparisons reproducible. WHERE isolates high-risk subgroups, GROUP BY compares outcomes across financial and academic categories, HAVING prevents tiny groups from driving conclusions, and JOIN connects student outcomes to program context such as attendance shift.

Data Exploration

Finding Patterns in the Data

Objective: explore the data before making final charts. This section checks score patterns, group differences, relationships, trends, outliers, missing data, and unusual records.

1. Admission Grade Distribution

Source & method: Kaggle dataset grouped Admission grade into score ranges to inspect the main distribution.

Observation: Scores cluster around 125-135. Interpretation: Most students enter with mid-range prior preparation. Research Implication: Admission grade alone is useful but not sufficient for dropout prediction.

2. Approved Units by Outcome

Source & method: Kaggle dataset grouped Curricular units 1st sem approved by Target outcome and summarized quartiles/medians.

Observation: Dropouts approve far fewer first-semester units. Interpretation: Early academic progress separates outcomes quickly. Research Implication: First-semester credit completion should be an early alert metric.

3. Tuition Status and Outcome

Source & method: Kaggle dataset grouped Tuition fees up to date by Target and converted the outcome counts to percentages.

Observation: Students with fees in arrears are mostly dropouts. Interpretation: Financial instability strongly aligns with attrition. Research Implication: Payment status should be studied as a primary intervention variable.

4. Age vs. Semester Grade

Source & method: Kaggle dataset compared Age at enrollment with Curricular units 1st sem grade and colored records by Target.

Observation: Older students show wider grade spread. Interpretation: Non-traditional students may face more varied academic constraints. Research Implication: Age should be tested with attendance shift and financial variables.

5. Correlation Matrix

Source & method: Kaggle dataset numeric fields were compared with pairwise correlation checks to identify stronger positive and negative relationships.

Observation: Approved units and semester grade move together, while dropout risk moves opposite. Interpretation: Academic progress variables are tightly related. Research Implication: Modeling should watch for overlapping predictors.

6. Economic Indicator Trend

Source & method: Kaggle dataset cohort-level unemployment and dropout summaries were compared to explore macroeconomic context.

Observation: Dropout rate rises in cohorts with higher unemployment. Interpretation: External labor conditions may compound student risk. Research Implication: Macroeconomic variables belong in contextual analysis.

7. Missing-Data Pattern

Source & method: Kaggle dataset fields were profiled for missing percentages and compared across dropout and non-dropout records.

Observation: Missingness is low but concentrated in grade-related fields. Interpretation: Missing academic values may reflect early non-participation. Research Implication: Missingness itself can be an attrition signal.

8. Outlier and Anomaly Scan

Source & method: Kaggle dataset numeric variables were scanned with range checks and IQR-style low/high outlier flags.

Observation: A small group has high age or very low approved units. Interpretation: These are likely legitimate high-risk cases, not automatic errors. Research Implication: Outliers should be flagged and analyzed, not silently removed.

3-5 Findings for the Results Section

Finding 1: Tuition fee arrears produce the clearest dropout separation and should anchor the intervention discussion.
Finding 2: First-semester approved units are a strong early academic warning measure.
Finding 3: Low semester grades and low unit completion reinforce each other as academic risk signals.
Finding 4: Older and evening students require contextual support because risk is partly structural.
Finding 5: Missing academic activity and anomalous low-credit records should be documented because they may represent disengagement before formal dropout.

Finding 1

Tuition payment status is strongly associated with dropout risk

Research Question

Does unpaid tuition separate dropouts from students who remain enrolled or graduate?

Evidence

86.6% of students with unpaid fees dropped out, compared with 24.7% of students whose fees were current.

Visualization

Tuition Status and Outcome chart; redesign Finding 1.

Analysis

The group with unpaid fees is overwhelmingly concentrated in the dropout category.

Interpretation

Financial instability appears to be one of the strongest actionable early-warning signals.

Finding 2

First-semester completion separates dropout and graduate outcomes

Research Question

Are approved first-semester units associated with student outcome?

Evidence

Median approved units: Dropout 2, Enrolled 5, Graduate 6. Students with fewer than 3 approved units had a 77.1% dropout rate.

Visualization

Approved Units by Outcome chart; redesign Finding 2.

Analysis

Academic progress shows a clear ordered pattern from dropout to enrolled to graduate.

Interpretation

Early credit completion should be used as an advisor alert before the second semester.

Finding 3

Low grades and low completion reinforce academic risk

Research Question

Which academic variables appear related to dropout?

Evidence

Dropout correlation: first-semester approved units -0.479, first-semester grade -0.481, second-semester grade -0.572.

Visualization

Correlation Matrix and Age vs. Semester Grade charts.

Analysis

Higher grades and more approved units move opposite dropout risk, making them overlapping but meaningful predictors.

Interpretation

Academic support should combine tutoring, course-load review, and progress monitoring.

Finding 4

Dropout risk rises for older and evening students

Research Question

How does dropout risk change by age and attendance context?

Evidence

Dropout rate rises from 22.1% for ages 18-21 to 57.6% for ages 26-35. Evening students show 42.9% dropout versus 30.8% for daytime students.

Visualization

Age vs. Semester Grade chart; redesign Finding 4.

Analysis

Non-traditional students show higher attrition, suggesting outside responsibilities may affect persistence.

Interpretation

Flexible advising and evening support should be part of retention planning.

Finding 5

Machine learning confirms that nonlinear ensembles best fit this task

Research Question

Which model best predicts dropout, enrolled, and graduate outcomes?

Evidence

10 models were evaluated. Random Forest ranked first at 77.9% accuracy; Extra Trees and Histogram Gradient Boosting followed at 76.7%.

Visualization

Model accuracy bar graph, score table, and Random Forest confusion matrix on the Models page.

Analysis

Tree ensembles performed best because they can combine financial, academic, and background variables without assuming a simple linear relationship.

Interpretation

The final Results section should present Random Forest as the best classifier while noting persistent difficulty identifying the enrolled middle category.
