Model Explanations

What each model does and why it matters

Each model uses the same student-retention dataset but learns patterns differently. Comparing them helps show whether the problem is handled better by simple rules, linear relationships, distance-based matching, or tree-based ensembles.

Random Forest

88.4%

Builds many decision trees and combines their votes. It performs best because it can capture non-linear patterns across grades, approved units, tuition status, scholarships, age, and schedule while staying more stable than one tree.

Gradient Boosting

87.2%

Builds trees one after another, with each new tree correcting mistakes from the previous trees. It is strong for prediction, but it can be more sensitive to tuning than Random Forest.

Support Vector Machine

84.9%

Finds boundaries that separate outcome groups as cleanly as possible. It works well when groups have a clear margin, but its decisions are harder to explain to advisors than tree rules.

Decision Tree

83.0%

Splits students into branches using rules such as tuition paid, approved units, and grades. It is easy to understand, but a single tree can overfit and miss broader patterns.

Logistic Regression

82.1%

Estimates the probability of each student outcome from weighted input features. It is useful because it is readable and shows which variables push risk higher or lower.

K-Nearest Neighbors

79.6%

Classifies a student by looking at the most similar students in the training data. It is intuitive, but it depends heavily on scaled features and can struggle when many variables interact.

Naive Bayes

73.6%

Uses probability rules to estimate the most likely outcome. It is fast and simple, but its independence assumptions are limiting because student factors like grades and approved units are related.

Majority Class Baseline

50.0%

Always predicts the most common outcome. It is not a useful final model, but it sets the minimum benchmark every real model should beat.

Model Takeaway

Best model

Random Forest has the top accuracy at 88.4% and is the best candidate for the final student-risk classifier.

Why it wins

It captures non-linear patterns across tuition status, approved units, grades, age, scholarship status, and class schedule.
